# Partials Tracker

Track partials weighed per shift against a daily target. Works on iPhone, Android and desktop, and installs to the home screen.

- Set the daily target, log each weigher's partials, LOT/IM number, batch name and batch size.
- Completion % = partials weighed / that day's target.
- Export to Excel (.xlsx) or CSV. Light and dark themes.
- Data is saved on each device only. Export regularly.

## Install on a phone
Open the site in Safari (iPhone) or Chrome (Android), then Share > Add to Home Screen (iPhone) or Install app (Android).
